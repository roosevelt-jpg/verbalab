# ADR-0003: ElevenLabs-inspired product UI

- **Status:** Accepted
- **Date:** 2026-09-06
- **Phase:** VL-030 / VL-023 polish

## Context

The Phase 1 console started as a dark green shell. The product direction asked for UI/UX inspired by https://elevenlabs.io/.

## Decision

Adopt a **light, monochrome, spacious** system: white canvas, black primary CTAs, soft gray panels, Syne + DM Sans, sparse forest-green brand accent. Public docs/playground match the same language.

## Consequences

Dark theme is not the default. Marketing and console share one design system. Further motion/polish can layer on without changing tokens.
